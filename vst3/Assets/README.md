# Sketch artwork

Faceplate.png is a static artwork plate generated from the user's approved Afterglow concept. All faders, numeric values, filter handles, switches and menus are native interactive JUCE components drawn separately; artwork contains no baked-in parameter values.

Caveat.ttf is the Caveat variable handwriting font from Google Fonts (github.com/google/fonts/tree/main/ofl/caveat), distributed under the included SIL Open Font License, Caveat-OFL.txt. The font is embedded, so Windows users do not need to install it.

Faceplate reference coordinates: 1664 x 944. The editor scales the complete component tree with a locked aspect ratio. The irregular paths are deterministic and repaint without random jitter. Raster faceplate is drawn at its original resolution at maximum editor size; moving controls are vector paths.
